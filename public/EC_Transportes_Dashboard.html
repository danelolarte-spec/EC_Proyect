✉ Enviar Dashboard por Correo

Para enviar el reporte automáticamente necesitas configurar el acceso a Gmail y Google Drive usando OAuth 2.0. Sigue estos pasos una sola vez:

1
Google Cloud Console

Entra a console.cloud.google.com, crea un proyecto y habilita las APIs: Gmail API y Drive API.

2
Credenciales OAuth 2.0

En "Credenciales" → "Crear credenciales" → "ID de cliente OAuth" → Tipo: Aplicación de escritorio. Descarga el credentials.json.

3
Script Python incluido

Usa el archivo EC_Dashboard_GoogleDrive.py con el mismo archivo .xlsx. Pon el credentials.json en la misma carpeta y ejecuta: python EC_Dashboard_GoogleDrive.py archivo.xlsx

4
Destinatarios configurados

El correo se enviará a: gerenciademarca@ectransportes.com
